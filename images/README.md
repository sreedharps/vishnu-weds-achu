# Wedding Invitation Photo Gallery

Place all wedding photos and couple portraits in this `images/` directory.

### Current Files
- `1.jpeg` - Recommended for Hero Banner / Couple Portrait (used as Open Graph thumbnail preview)
- `2.jpeg` - Gallery Photo 1 (e.g. Engagement / Candid)
- `3.jpeg` - Gallery Photo 2 (e.g. Traditional Attire)
- `4.jpeg` - Gallery Photo 3 (e.g. Pre-wedding shoot)
- `5.jpeg` - Gallery Photo 4 (e.g. Haldi / Mehendi moment)
- `6.jpeg` - Gallery Photo 5 (e.g. Sangeet / Celebration)
- `7.jpeg` - Gallery Photo 6 (e.g. Sunset / Outdoor portrait)

### Tips for Best Visual Quality:
1. **Aspect Ratio**: Portrait (3:4 or 4:5) and Landscape (16:9 or 3:2) both work seamlessly with the responsive masonry/grid gallery.
2. **File Size**: Compress images (under 500KB - 1MB each) using tools like TinyPNG or squoosh.app for lightning-fast mobile loading.
3. **Thumbnail**: `1.jpeg` is referenced in `index.html`'s `<meta property="og:image">` for WhatsApp / Facebook link previews. Keep it high quality and centered.
